🔔 Notification Prompt Demo

This page demonstrates the automatic notification permission prompt system. The prompt will appear 3 seconds after page load if you haven't enabled notifications yet.

🎯 Smart Timing

Appears after 3 seconds, giving users time to engage with your content first.

🚫 Respects Dismissals

If dismissed, won't show again for 7 days to avoid annoying users.

📱 Mobile Friendly

Fully responsive design that works beautifully on all devices.

✨ Smooth UX

Beautiful animations and clear feedback for all user actions.

ℹ️ How It Works

The notification prompt automatically checks your browser's permission status. If you haven't granted or denied permission yet, you'll see a friendly banner at the top of the page. Try refreshing the page to see it again, or use the controls below to test manually.

To use this on your site, simply include notification-prompt.js in your HTML. It will automatically initialize and show the prompt when appropriate. See the admin panel's Notification Settings page for full documentation.
